# Overview

Open-source Python engine for network data collection, parsing and structured observations.

NipStack Core V1 is under development. APIs, connectors and official Features are introduced incrementally; consult the current code and public Issues for implemented functionality.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for the contributor workflow and local checks, and [coding standards](docs/developer/coding-standards.md) for maintainability, typing, comments, docstrings and testing conventions. Coding agents and human contributors must also follow the applicable [AGENTS.md](AGENTS.md) instructions.
